Live MIDI-Aufnahme (Overdub)

Bei aktiviertem ●-Record werden eingehende MIDI-Noten als aktive Steps im aktuellen Pattern eingetragen. Die Velocity kommt direkt vom MIDI-Signal. Bestehende Steps werden nicht überschrieben (Overdub-Modus).

Tap Tempo

Mehrfach T drücken — der Durchschnitt der letzten Tippen-Abstände wird als BPM übernommen. Nützlich, um sich einem laufenden Track anzupassen.

Metronom

Das Metronom ist über die Einstellungen konfigurierbar: Ton (Pitch), Lautstärke und Subdivisions (Achtel, Sechzehntel). Es läuft über den Master-Audioausgang.

Time-Stretch

In der Statusleiste unten: Slider für den aktiven Kanal im Bereich 0,25× bis 4,0×. Bei 2× wird die Sample-Dauer verdoppelt ohne Pitch-Änderung. Klick auf den Wert setzt ihn auf 1× zurück.

Euclidean Rhythm Generator

Das ⬡ Poly-Menü öffnet den Euclidean Generator. Gib die Anzahl der Impulse (E) und die Schrittlänge (N) ein — Synthstudio verteilt die Impulse gleichmäßig über das Raster. Klassisches Beispiel: E=3, N=8 = Tresillo-Rhythmus.

06 Step Inspector

Klick oder Rechtsklick auf einen Step öffnet den Inspector unterhalb der Kanäle. Hier können alle Feinparameter eines einzelnen Steps gesetzt werden.

ParameterBereichBeschreibung
Velocity1–127Anschlagsstärke. Schnellwerte: 32, 64, 96, 127
Pitch−24..+24 HalbtöneTransposition in Halbtönen; Notenname wird angezeigt (z.B. F#4)
Wahrscheinlichkeit0–100%Wie oft der Step tatsächlich spielt. 75% = jeder 4. Step fällt aus
BedingungImmer / 1:2 / 2:2 / Fill / …Elektron-Stil: Step nur unter bestimmten Umständen (z.B. nur auf 2. Durchlauf)
ReverseAn/AusSample rückwärts abspielen
Param LockFilter Hz / Volume / Pan / Reverb / DelayPer-Step FX-Override — gilt nur für diesen einen Step

Parameter Locks (Trig Locks)

Mit + im Inspector kann ein beliebiger Effektparameter für genau diesen Step überschrieben werden. Nach dem Step werden alle Parameter automatisch restauriert. So klingt z.B. Step 3 mit einem Filter-Sweep während alle anderen normal bleiben — ohne die Kanal-FX zu verändern.

Inspiration: Parameter Locks sind von Elektron-Hardware (Machinedrum, Digitakt) inspiriert und ermöglichen dramatische Step-für-Step Variationen ohne separate Spuren.

08 Live Pattern Editing

Ändere Patterns während der Wiedergabe — ohne Rhythmus-Unterbrechung.

● LIVE EDIT ▶ spielt: Pattern 1  /  ✏ bearbeite: Pattern 1 [DRAFT]
✓ Commit ⏱ Nächste Bar ✕ Verwerfen

Ablauf

1. Klick auf ● Live Edit erstellt einen [DRAFT]-Klon des aktiven Patterns.
2. Das Original spielt weiter unverändert. Der Draft wird zum Bearbeitungsziel.
3. Steps im Grid bearbeiten — Änderungen betreffen nur den Draft.
4. ✓ Commit wechselt sofort zum Draft.
5. ⏱ Nächste Bar wartet auf den nächsten Bar-Anfang für nahtlosen Übergang.
6. ✕ Verwerfen löscht den Draft, Original bleibt.
